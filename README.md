# AGP HoraHora Opaco

Sistema digital de controle de produção para a linha de mantas de aramida opaca da AGP.

## Funcionalidades

- **Dashboard em tempo real** — cortados, embolsados, autoclave, aprovados, reprovados e amostras
- **Fluxo de produção visual** — Corte → Embolsamento → Autoclave → Aprovados → Amostras
- **Taxa de aprovação** da autoclave com gráfico circular
- **Gráficos** de produção por dia, semana e mês
- **Registro por intervalo de hora** (07h→08h, 08h→09h, etc.)
- **Motivo de parada obrigatório** quando produção zerada
- **Rastreabilidade individual por painel** com código de 8 dígitos
- **Controle de retrabalho** com tipo de defeito e descrição livre
- **Histórico completo** por hora e por painel com timeline

## Tecnologias

- React 18
- Recharts
- Vite

## Como rodar

```bash
npm install
npm run dev
```
